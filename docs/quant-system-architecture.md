# QuantBot Builder: 시스템 설계 기준서

> 봇 개발 시 이 문서를 기준으로 아키텍처와 파라미터를 설계한다.

---

## 0. 개인 트레이딩 시스템 전제 조건

개인 투자자 환경(클라우드 VPS, 일반 인터넷)에서 구동되므로 다음을 전제로 한다.

| 항목 | 원칙 |
|------|------|
| HFT/순수 차익거래 | **배제** — 코로케이션/FPGA 없이 속도 경쟁 불가 |
| 유리한 전략 | 수 분 ~ 수 주 단위 스윙/포지셔널에 집중 |
| 우선순위 | 속도(latency)보다 **안정성(uptime 99.9%+)** |
| 마찰 비용 | 기관보다 높은 수수료/슬리피지를 상쇄할 충분한 Edge 필요 |

## 1. 4단계 모듈 아키텍처

시스템은 4개 레이어로 철저히 분리한다.

```
[1] 데이터 레이어 → [2] 알파/전략 레이어 → [3] 리스크 레이어 → [4] 주문 집행 레이어
```

### 1-1. 데이터 레이어 (Data Layer)
- OHLCV + 오더북(호가창) 수집
- 기술적 지표 계산 (MA, RSI, BB, MACD 등)
- 대안 데이터: 뉴스/소셜 감성 → -1 ~ +1 수치 변환
- **데이터 무결성**: 결측치 처리, 이상치 제거, 미래 데이터 유출(Data Leakage) 방지

### 1-2. 알파/전략 레이어 (Alpha Layer)
- **추세 추종**: 이동평균 돌파, 변동성 높은 장세에 유리
- **평균 회귀**: BB 이탈 후 회귀, RSI 과매수/과매도
- **시장 국면 판별(Regime Detection)**: ATR/VIX로 추세장 vs 횡보장 판별 → 전략 비중 동적 조절

### 1-3. 리스크 관리 레이어 (Risk Layer)

> 알파 시그널은 **절대 바로 주문으로 연결하지 않는다.** 리스크 엔진이 기각/축소 최종 권한 보유.

**포지션 사이징:**

| 방식 | 설명 |
|------|------|
| 고정 비율 (Fixed Fractional) | 1회 거래당 총자본의 1~2%만 위험 노출 |
| 켈리 베팅 (Kelly Criterion) | Fractional Kelly만 적용 (Half-Kelly, 25% Kelly 등) |
| 변동성 기반 (Volatility-adjusted) | ATR 활용, 변동성 클수록 포지션 축소 |

**하드코딩 안전장치 (Kill Switches):**
- 일일/누적 최대 손실(Max Drawdown) 초과 시 → 즉시 청산 + 24시간 매매 중단
- 단일 종목 포지션 한도 제한

### 1-4. 주문 집행 레이어 (Execution Layer)
- 큰 주문은 **TWAP/VWAP**으로 분할 전송 (시장 충격 최소화)
- API Rate Limit 준수 (토큰 버킷 알고리즘)
- 네트워크 단절 대비: 타임아웃 + 재시도(Retry) 로직

## 2. 백테스트 및 검증

| 항목 | 기준 |
|------|------|
| 미래 참조 방지 | t 시점에 t+1 데이터 유입 금지, `shift(1)` 강제 |
| 과적합 방지 | Walk-Forward Analysis (학습 → 검증 → 이동) |
| 비용 반영 | 수수료 + 스프레드 + 슬리피지 차감 후 수익률 계산 |

**필수 평가 지표:**
- CAGR (연평균 수익률)
- Sharpe Ratio
- MDD (최대 낙폭)
- Profit Factor

## 3. 보안 원칙

| 항목 | 규칙 |
|------|------|
| API 키 권한 | Read + Trade만 허용. **출금(Withdrawal) 절대 금지** |
| IP 제한 | 봇 서버 고정 IP만 화이트리스트 |
| 시크릿 관리 | 환경 변수로만 호출, 소스코드에 평문 하드코딩 금지 |

## 4. 시그니처 설계 시 적용 가이드

이 문서의 원칙을 시그니처(Signature) 파라미터에 반영할 때:

1. **진입(Judgment)**: 단일 지표가 아닌, 추세 + 모멘텀 + 변동성 복합 판단
2. **청산(Defense)**: 고정 비율 외에 ATR 기반 동적 손절, 트레일링 스탑
3. **포지션(Action)**: 고정 비율 + 변동성 기반 사이징 선택 가능
4. **리스크**: 전략 레벨(손절/익절)과 봇 레벨(킬 스위치) 분리
5. **시장 필터(Regime)**: 추세/횡보 판별 → 전략 on/off 또는 파라미터 자동 조절
