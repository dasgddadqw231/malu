## 핵심 개념

| 용어 | 설명 |
|------|------|
| **시그니처(Signature)** | AI가 생성한 트레이딩 전략. 볼린저 밴드/RSI 진입 조건, 손절/익절 비율, 포지션 크기, 사이클 간격 등을 포함 |
| **봇(Bot)** | 시그니처를 실제 심볼에 예산과 함께 배포한 자동매매 인스턴스 |
| **데이터셋(Dataset)** | 바이빗 수동 거래 내역을 모아둔 컬렉션. AI가 시그니처를 만들 때 참고 자료로 사용 |
| **봇 컨트롤(Bot Controls)** | 전략과 별개로 봇에 거는 리스크 안전장치 (일일 최대 손실, 연속 손실 제한 등) |
| **킬 스위치(Kill Switch)** | 모든 봇을 즉시 정지하고 열린 포지션을 시장가로 청산하는 비상 버튼 |

## 1. 대시보드 (홈)

경로: `/`

시스템 전체 상태를 한눈에 볼 수 있는 메인 화면입니다.

### 상단 HUD 요약

| 항목 | 설명 |
|------|------|
| Total PnL | 전체 손익 (초록: 수익, 빨강: 손실) |
| Total Bots | 등록된 봇 수 |
| Active | 현재 가동 중인 봇 수 |
| Available | 사용 가능한 예산 |
| Kill Switch | 킬 스위치 상태 (STANDBY / ARMED) |

### 봇 카드

각 봇이 카드 형태로 표시됩니다.

**카드에 표시되는 정보:**
- 봇 이름, 상태 표시등 (가동 중이면 애니메이션)
- 심볼 (예: BTCUSDT), 전략 유형 뱃지
- 예산 현황: SEED(초기) / USED(사용중) / AVAIL(가용) + 진행 바

**봇 상태별 의미:**
- `RUNNING` — 전략 사이클 실행 중
- `WAITING` — 다음 사이클 대기 중
- `IN POSITION` — 포지션 보유 중
- `JUDGING` — 시장 조건 분석 중
- `EXECUTING` — 주문 실행 중
- `DEFENDING` — 포지션 관리 중 (손절/익절 감시)
- `OFFLINE` — 수동 정지
- `KILLED` — 강제 종료
- `ERROR` — 오류 발생

**버튼 (정지된 봇):**
- `DEPLOY` — 봇 시작
- `EDIT` — 설정 편집 (이름, 예산, 리스크 컨트롤)
- `DEL` — 봇 삭제

**버튼 (가동 중인 봇):**
- `HALT` — 현재 사이클 완료 후 안전 정지
- `KILL` — 즉시 강제 종료

**카드 클릭 → 봇 로그 모달:**
- `LOGS` 탭: 실시간 이벤트 스트림 (WebSocket)
- `TRADES` 탭: 해당 봇의 거래 내역

### 킬 스위치

`KILL ALL` 버튼 → 확인 팝업 → **모든 봇 정지 + 열린 포지션 시장가 청산**

킬 스위치가 작동하면 `ARMED` 상태가 되며, `RESET KILL SWITCH`를 눌러야 봇을 다시 시작할 수 있습니다.

### 상단 네비게이션

- `MANUAL TRADES` → 수동 거래 내역
- `BOT TRADES` → 봇 거래 내역
- `SIGNATURE` → 시그니처 라이브러리

## 2. 수동 트레이드 관리

경로: `/trades`

바이빗에서 직접 한 거래 내역을 동기화하고 관리합니다.

### 사용법

1. **거래 동기화**: 상단 `SYNC TRADES` 버튼 클릭 → 바이빗에서 최신 거래 내역 가져오기
2. **심볼 필터**: 드롭다운으로 특정 코인만 필터링 (BTC, ETH 등)
3. **메모 추가**: 거래 행의 Rationale/Tags 열 클릭 → 매매 이유와 태그(쉼표 구분) 입력 → SAVE
4. **데이터셋 만들기**:
   - 체크박스로 원하는 거래들 선택
   - 상단에 "N trades selected" 바가 나타남
   - `CREATE DATASET` 클릭
   - 이름 입력, 설명(선택), Auto-sync 여부 설정
   - `CREATE` → 데이터셋 상세 페이지로 이동

---

## 3. 데이터셋

### 데이터셋 목록

경로: `/datasets`

저장된 데이터셋 목록을 확인합니다. 각 카드에 이름, 거래 수, AUTO 뱃지(자동 동기화 여부)가 표시됩니다.

### 데이터셋 상세

경로: `/datasets/{id}`

**기능:**
- `EDIT` → 이름, 설명, Auto-sync 설정 변경
- `SYNC` → 바이빗에서 새 거래를 가져와 데이터셋에 추가
- `CSV` → CSV 파일 업로드로 거래 일괄 추가
- 각 거래 행의 휴지통 아이콘 → 데이터셋에서 제거 (원본 거래는 유지)

## 4. 시그니처 (전략)

### 시그니처 목록

경로: `/diy`

만들어둔 트레이딩 전략들의 라이브러리입니다.

**카드에 표시되는 정보:**
- 전략 이름, 설명
- 유형 뱃지: `NL`(자연어 기반) 또는 `TRADE`(거래 데이터 기반)
- 통계: 총 거래 수, 승률, 평균 PnL, 총 PnL
- 설정 요약: 손절 %, 익절 %, 사이클 간격
- 전략 규칙 목록

**각 카드의 버튼:**
- `EDIT` → AI 채팅으로 전략 수정
- `BACKTEST` → 클릭하면 인라인 폼 표시 (심볼, 초기 자본, 시작/종료일) → `RUN`
- `DELETE` → 시그니처 삭제

### 새 시그니처 만들기

경로: `/diy/new`

AI와 대화하며 전략을 만드는 화면입니다.

**순서:**
1. 시그니처 이름 입력
2. (선택) 참고할 데이터셋 선택 — AI가 실제 거래 패턴을 분석해서 전략에 반영
3. 채팅 시작 — 원하는 전략을 자연어로 설명

**프롬프트 예시:**
- "보수적으로 소액 단타"
- "공격적 진입, 손절 2% 익절 6%"
- "스윙, 안전하게 작은 포지션"
- "스캘핑, 빠른 주기, 타이트한 손익절"

4. AI가 응답할 때마다 오른쪽 **LIVE PREVIEW** 패널이 업데이트됨:
   - 볼린저 밴드 설정 (기간, 표준편차)
   - RSI 설정 (기간, 과매도/과매수 기준)
   - 포지션 크기 %, 손절 %, 익절 %
   - 사이클 간격
   - 전략 규칙 (상황 → 행동 쌍)
5. 대화를 계속하며 전략 수정 가능
6. 만족하면 `DONE` 클릭 → 시그니처 목록으로 이동

### 시그니처 편집

경로: `/diy/{id}/edit`

기존 시그니처의 대화 이력이 로드되고, 이어서 대화하며 수정할 수 있습니다.

## 5. 백테스트

경로: `/backtest`

과거 데이터로 전략을 시뮬레이션한 결과를 확인합니다.

**진입 경로:** 시그니처 카드의 `BACKTEST` 버튼 → 설정 입력 → `RUN`

### 결과 화면

각 백테스트 실행이 카드로 표시됩니다.

**카드 요약:**
- 심볼, 상태 (RUNNING / COMPLETED / ERROR), 간격, 기간

**카드 클릭 시 펼쳐지는 상세:**
| 지표 | 설명 |
|------|------|
| Net PnL | 수수료 차감 후 순수익 |
| Total PnL | 수수료 미차감 총수익 |
| Fees | 발생한 총 수수료 |
| Win Rate | 승률 (%) |
| Drawdown | 최대 낙폭 (%) |
| Sharpe | 샤프 비율 (1 이상이면 양호) |

**에쿼티 커브:** 초기 자본 대비 자산 변화를 바 차트로 시각화 (초록: 수익 구간, 빨강: 손실 구간)

**거래 테이블:** 각 거래의 방향(LONG/SHORT), 진입가, 청산가, 수량, 손익, 수수료, 청산 사유

실행 중인 백테스트는 2초마다 자동 새로고침됩니다.

## 6. 봇 배포

경로: `/deploy`

시그니처를 실제 자동매매 봇으로 배포하는 4단계 마법사입니다.

### Step 1 — 대상 심볼 선택
- BTC, ETH 빠른 선택 버튼 제공
- 직접 입력도 가능 (예: SOLUSDT)

### Step 2 — 예산 설정
- 투입할 금액(USD) 입력
- 현재 사용 가능한 예산이 표시됨

### Step 3 — 시그니처 선택
- 만들어둔 시그니처 목록에서 선택
- 시그니처가 없으면 `/diy`로 이동하는 링크 표시

### Step 4 — 봇 컨트롤 (리스크 관리)

프리셋으로 빠르게 설정하거나, 고급 설정으로 세부 조정 가능합니다.

| 프리셋 | 일일 최대 손실 | 연속 손실 제한 | 일일 최대 거래 | 쿨다운 |
|--------|---------------|---------------|---------------|--------|
| OFF | 제한 없음 | 제한 없음 | 제한 없음 | 없음 |
| CONSERVATIVE | -3% | 2회 | 10회 | 120초 |
| MODERATE | -5% | 3회 | 20회 | 60초 |
| AGGRESSIVE | -10% | 5회 | 무제한 | 없음 |

**고급 설정(ADVANCED):**
- 포지션 크기 모드: 전략 비율(%) 또는 고정 금액($)
- 복리(Compound) 여부

### 배포 완료
오른쪽 미리보기 패널에서 설정을 확인 → `INITIALIZE BOT` 클릭 → 대시보드로 이동

## 7. 봇 거래 내역

경로: `/bot-trades`

모든 봇의 거래 실행 기록을 확인합니다.

**상단 요약:** 총 거래 수, 총 PnL, 승리 횟수, 패배 횟수

**필터:** 특정 봇만 선택해서 조회 가능

---

## 전체 흐름 요약

```
1. 바이빗 거래 동기화
   /trades → SYNC TRADES

2. 데이터셋 만들기 (선택)
   /trades → 거래 선택 → CREATE DATASET

3. AI로 전략 만들기
   /diy → NEW SIGNATURE → 채팅으로 전략 설계

4. 백테스트로 검증
   /diy → 시그니처 카드의 BACKTEST → 결과 확인

5. 봇 배포
   /deploy → 심볼 → 예산 → 시그니처 → 리스크 설정 → INITIALIZE

6. 모니터링
   / (대시보드) → 봇 카드 클릭으로 실시간 로그 확인
```
