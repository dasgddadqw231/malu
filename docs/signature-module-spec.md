# 시그니처 모듈 설계서

> 시그니처 = 교체 가능한 모듈 4개의 조합
> 각 모듈은 독립적으로 백테스트 비교 가능

---

## 전체 구조

```
시그니처 = {
    meta:   { archetype, timeframe, pair }
    entry:  진입 모듈 1개 선택
    exit:   청산 모듈 1개 선택
    sizing: 사이징 모듈 1개 선택
    filter: 필터 모듈 0~N개 선택 (선택사항)
}
```

**흐름:**
```
[필터] 지금 거래해도 되는 장인가? ──NO──→ 대기
         │YES
[진입] 신호 발생했나? ──NO──→ 대기
         │YES
[사이징] 얼마나 넣을지 계산
         │
[집행] 주문 실행
         │
[청산] 조건 충족 시 나감
```

---

## A. 진입 모듈 (Entry)

> "언제 들어갈 것인가"

각 모듈은 캔들 데이터를 받아서 `LONG / SHORT / HOLD` 신호를 리턴한다.
현재 코드의 `JudgmentModule` 인터페이스를 그대로 활용.

### A-1. `bb_reversal` — 볼린저 밴드 반전 (현재 구현됨)

**전략 유형**: 평균 회귀 (횡보장에서 유리)

가격이 볼린저 밴드 바깥으로 이탈하면 되돌아올 것을 기대하고 역방향 진입.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| bb_period | 10~50 | 20 | 볼린저밴드 이동평균 기간 |
| bb_std | 1.0~3.0 | 2.0 | 표준편차 배수 |
| rsi_period | 7~28 | 14 | RSI 확인용 |
| rsi_oversold | 15~45 | 30 | 과매도 기준 |
| rsi_overbought | 55~85 | 70 | 과매수 기준 |

**진입 조건:**
- 롱: 종가 <= 하단밴드 AND RSI < 과매도
- 숏: 종가 >= 상단밴드 AND RSI > 과매수

**적합한 장세:** 횡보장, 박스권
**기대 승률:** 55~65% (R:R 1:1~1.5)

---

### A-2. `bb_squeeze` — 볼린저 밴드 스퀴즈 돌파 (신규)

**전략 유형**: 브레이크아웃 (횡보→추세 전환에서 유리)

밴드폭이 극도로 좁아진 후(스퀴즈) 터지는 방향으로 진입.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| bb_period | 10~50 | 20 | 볼린저밴드 기간 |
| bb_std | 1.5~3.0 | 2.0 | 표준편차 배수 |
| squeeze_lookback | 20~100 | 48 | 스퀴즈 판단 기간 (N봉 최저 밴드폭) |
| squeeze_percentile | 5~30 | 20 | 하위 N% 이하면 스퀴즈 |
| volume_multiple | 1.0~3.0 | 1.5 | 돌파 시 필요 거래량 배수 |

**진입 조건:**
1. 밴드폭(BandWidth)이 최근 N봉 중 하위 20%
2. 종가가 밴드 바깥으로 **종가 마감** (위크 무시)
3. 거래량 >= 20기간 평균의 1.5배

**적합한 장세:** 장기 횡보 후 돌파 구간
**기대 승률:** 40~50% (R:R 2:1 이상)

---

### A-3. `ema_cross` — EMA 크로스오버 (신규)

**전략 유형**: 추세 추종 (추세장에서 유리)

단기 이동평균이 장기 이동평균을 돌파하면 추세 시작으로 판단.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| fast_period | 5~50 | 9 | 단기 EMA 기간 |
| slow_period | 20~200 | 21 | 장기 EMA 기간 |
| trend_ema | 100~200 | 200 | 추세 확인용 장기 EMA (선택) |
| require_trend | true/false | true | 장기 추세 방향과 일치할 때만 진입 |

**진입 조건:**
- 롱: fast EMA > slow EMA 크로스 발생 (+ 가격 > 200 EMA면 더 강한 신호)
- 숏: fast EMA < slow EMA 크로스 발생 (+ 가격 < 200 EMA면 더 강한 신호)

**타임프레임별 추천 조합:**
- 스캘핑 (1m~15m): 9/21
- 스윙 (1h~4h): 20/50
- 포지션 (1d): 50/200 (골든크로스/데스크로스)

**적합한 장세:** 뚜렷한 추세장
**기대 승률:** 40~50% (R:R 2:1 이상, 추세를 길게 타서 수익)

---

### A-4. `macd_cross` — MACD 크로스오버 (신규)

**전략 유형**: 추세/모멘텀 (추세 초입 포착)

MACD선이 시그널선을 돌파할 때 진입. 제로라인 기준으로 신호 강도 판단.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| fast_ema | 5~20 | 12 | MACD 빠른 EMA |
| slow_ema | 15~40 | 26 | MACD 느린 EMA |
| signal_period | 5~15 | 9 | 시그널선 기간 |
| require_zero_cross | true/false | false | 제로라인 아래에서 올라올 때만 롱 (강한 필터) |

**진입 조건:**
- 롱: MACD선 > 시그널선 크로스 (제로라인 아래에서 발생하면 강한 신호)
- 숏: MACD선 < 시그널선 크로스 (제로라인 위에서 발생하면 강한 신호)

**적합한 장세:** 추세 전환 초기
**기대 승률:** 40~55%

---

### A-5. `rsi_divergence` — RSI 다이버전스 (신규)

**전략 유형**: 반전 포착 (천장/바닥 잡기)

가격과 RSI의 방향이 엇갈릴 때 → 추세 반전 임박.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| rsi_period | 7~28 | 14 | RSI 기간 |
| lookback | 10~50 | 20 | 다이버전스 탐색 범위 (봉 수) |
| min_bars_between | 3~10 | 5 | 두 피봇 사이 최소 봉 수 |
| confirmation | true/false | true | RSI가 30/70을 다시 돌파할 때까지 대기 |

**진입 조건:**
- 불리시 다이버전스: 가격은 Lower Low, RSI는 Higher Low → 롱
- 베어리시 다이버전스: 가격은 Higher High, RSI는 Lower High → 숏

**적합한 장세:** 추세 막바지, 과매도/과매수 극단
**기대 승률:** 50~60% (4h, 1d에서 가장 유효)

---

### A-6. `confluence` — 복합 신호 (고급, 향후 구현)

**전략 유형**: 멀티 지표 합의

여러 지표를 동시에 체크해서 스코어링. 점수가 기준 이상이면 진입.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| indicators | - | - | 사용할 지표 목록 (아래 참고) |
| min_score | 2~5 | 3 | 최소 합의 점수 |
| boost_at_score | 3~5 | 4 | 이 점수 이상이면 포지션 1.5배 |

**스코어링 기준 (각 +1점):**

| 체크 항목 | +1 조건 |
|----------|---------|
| 추세 정렬 | 가격 > EMA 스택 정렬 |
| 모멘텀 확인 | RSI 또는 MACD 방향 일치 |
| 거래량 확인 | 거래량 > 20기간 평균 × 1.2 |
| 핵심 레벨 | 지지/저항, VWAP 근처 |
| 변동성 맥락 | BB/ATR이 유리한 상태 |

**적합한 장세:** 모든 장세 (필터 조합으로 적응)
**기대 승률:** 50~65% (높은 컨플루언스 = 높은 승률)

## B. 청산 모듈 (Exit)

> "언제 나갈 것인가"

현재 코드의 `DefenseModule` 인터페이스를 확장.

### B-1. `fixed_pct` — 고정 비율 손익절 (현재 구현됨)

가장 단순한 방식. 진입가 기준 고정 퍼센트.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| stop_loss_pct | 0.5~15% | 5.0 | 손절 비율 |
| take_profit_pct | 0.5~30% | 10.0 | 익절 비율 |

**동작:**
- 미실현 PnL <= -stop_loss_pct → 즉시 청산
- 미실현 PnL >= +take_profit_pct → 즉시 청산

**장점:** 단순, 이해 쉬움
**단점:** 변동성 무시, 추세장에서 수익 조기 컷

---

### B-2. `atr_stop` — ATR 기반 동적 손익절 (신규)

변동성에 따라 손절/익절 폭이 자동 조절.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| atr_period | 7~21 | 14 | ATR 계산 기간 |
| stop_atr_multiple | 1.0~4.0 | 2.0 | 손절 = 진입가 ± N×ATR |
| tp_atr_multiple | 1.5~6.0 | 3.0 | 익절 = 진입가 ± N×ATR |

**동작:**
- 진입 시 ATR 계산 → 손절/익절 가격 확정
- 변동성 크면 손절 넓게 → 노이즈에 안 걸림
- 변동성 작으면 손절 좁게 → 리스크 줄임

**Knowledge Base 근거:** "ATR-Based (Recommended)" — 모든 전략 유형에서 가장 권장되는 손절 방식

---

### B-3. `scaled_exit` — R배수 분할 청산 (신규)

수익이 커질수록 단계적으로 물량을 줄이면서 나머지는 트레일링.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| stop_method | "fixed"/"atr" | "atr" | 손절 방식 |
| stop_value | - | 2.0 | 고정이면 %, ATR이면 배수 |
| atr_period | 7~21 | 14 | ATR 기간 (ATR 방식일 때) |
| levels | - | 아래 참고 | 분할 청산 단계 |
| trail_method | "atr"/"ema"/"pct" | "atr" | 잔여 물량 트레일링 방식 |
| trail_value | - | 2.0 | 트레일링 ATR 배수 또는 % |

**기본 분할 청산 단계:**
```
1R 도달 → 25% 청산 + 손절을 본절로 이동
2R 도달 → 25% 청산 + 트레일링 시작
3R 도달 → 25% 청산
나머지 25% → 트레일링으로 추세 끝까지
```

*R = 리스크 단위. 손절 거리를 1R이라 하면, 익절 목표를 손절 거리의 배수로 표현*

**Knowledge Base 근거:** "Partial Exit Strategy (Recommended)" — 수익 극대화를 위한 핵심 기법

---

### B-4. `trailing_stop` — 트레일링 스탑 (신규)

고점 대비 일정 폭 하락하면 청산. 추세를 끝까지 탈 수 있음.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| method | "atr"/"ema"/"pct" | "atr" | 트레일링 기준 |
| atr_multiple | 1.5~4.0 | 2.0 | ATR 방식: 고점 - N×ATR |
| ema_period | 10~50 | 20 | EMA 방식: 종가 < EMA면 청산 |
| trail_pct | 1~10% | 3.0 | % 방식: 고점 대비 N% 하락 |
| activate_after_pct | 0~10% | 1.0 | 최소 N% 수익 후 트레일링 시작 |

**트레일링 방식 비교:**

| 방식 | 설명 | 추천 용도 |
|------|------|----------|
| ATR | 고점 - 2×ATR 아래로 빠지면 청산 | 추세추종 전반 |
| EMA | 종가가 20 EMA 아래로 마감하면 청산 | 스윙/포지션 |
| 고정% | 고점 대비 3% 하락 시 청산 | 스캘핑 |

**Knowledge Base 근거:** "Chandelier Exit", "ATR Trail" — 추세추종에서 필수

---

### B-5. `time_stop` — 시간 기반 청산 (신규)

정해진 봉 수 안에 목표 수익에 못 미치면 포지션 정리.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| max_candles | 3~100 | 20 | 최대 보유 봉 수 |
| min_profit_pct | 0~5% | 0.5 | 이 수익 미달이면 청산 |

**동작:**
- N봉 경과 후 수익이 기준 미달 → 청산 (본절 또는 소손실)
- "좋은 셋업은 빨리 움직인다. 안 움직이면 논리가 틀린 것"

**Knowledge Base 근거:** "Time-Based Stop" — 자본 묶임 방지

## C. 사이징 모듈 (Sizing)

> "얼마나 넣을 것인가"

현재 코드의 `ActionModule`에서 사이징 로직을 분리.

### C-1. `fixed_fraction` — 고정 비율 (현재 구현됨)

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| size_pct | 5~95% | 50 | 가용 자본 대비 투입 비율 |

**계산:** `주문 금액 = 가용 자본 × size_pct`

**장점:** 단순
**단점:** 변동성/리스크 무관하게 항상 같은 금액

---

### C-2. `risk_based` — 리스크 기반 (신규, 권장)

1회 거래 최대 손실을 자본의 N%로 고정하고, 손절 거리에서 역산.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| risk_per_trade | 0.1~3.0% | 1.0 | 1회 최대 허용 손실 (자본 대비) |

**계산:**
```
포지션 크기 = (자본 × risk_per_trade) / 손절 거리
```

예시: 자본 $10,000, risk 1%, 손절 2%
→ 최대 손실 = $100, 포지션 = $100 / 0.02 = **$5,000**

**손절이 넓으면 포지션 작아지고, 좁으면 커짐 → 항상 같은 금액만 잃음**

**Knowledge Base 근거:** "Fixed Fractional" — 1회 거래당 1~2%가 업계 표준

---

### C-3. `volatility_adjusted` — 변동성 기반 (신규, 고급)

ATR로 현재 변동성을 측정해서 포지션 크기 자동 조절.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| risk_per_trade | 0.1~3.0% | 1.0 | 1회 최대 허용 손실 |
| atr_period | 7~21 | 14 | ATR 계산 기간 |
| atr_multiple | 1.5~4.0 | 2.0 | 손절 거리 = N × ATR |

**계산:**
```
손절 거리 = ATR(14) × 2.0
포지션 크기 = (자본 × risk_per_trade) / 손절 거리
```

**효과:**
- 변동성 큰 장 → ATR 큼 → 포지션 자동 축소
- 변동성 작은 장 → ATR 작음 → 포지션 자동 확대
- 어떤 장세든 잃는 금액은 동일

**Knowledge Base 근거:**

| ATR/가격 비율 | 변동성 | 권장 레버리지 |
|--------------|--------|-------------|
| < 1.5% | 낮음 | 최대 10x |
| 1.5~3% | 보통 | 최대 5x |
| 3~5% | 높음 | 최대 3x |
| > 5% | 극단 | 1~2x |

## D. 필터 모듈 (Filter)

> "지금 거래해도 되는 장인가?"

필터는 0개~여러 개를 동시에 적용 가능. 하나라도 BLOCK이면 진입 안 함.

### D-1. `trend_filter` — 추세 필터

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| ema_period | 50~200 | 200 | 추세 판단 EMA |
| timeframe | - | "1d" | 필터 적용 타임프레임 |

**동작:**
- 가격 > EMA(200, 일봉) → 롱만 허용
- 가격 < EMA(200, 일봉) → 숏만 허용

**효과:** MACD 거짓 신호 30~40% 감소 (Knowledge Base 근거)

---

### D-2. `regime_filter` — 시장 국면 필터

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| method | "adx"/"atr_ratio"/"bb_width" | "adx" | 판별 방식 |
| adx_period | 7~28 | 14 | ADX 기간 |
| trending_threshold | 20~35 | 25 | 이상이면 추세장 |
| ranging_threshold | 15~25 | 20 | 이하면 횡보장 |
| allow_in_trend | - | ["ema_cross","macd_cross","bb_squeeze"] | 추세장에 허용할 진입 모듈 |
| allow_in_range | - | ["bb_reversal","rsi_divergence"] | 횡보장에 허용할 진입 모듈 |

**동작:**
```
ADX > 25 → 추세장 → 추세추종 진입만 허용
ADX < 20 → 횡보장 → 평균회귀 진입만 허용
20~25   → 전환기 → 포지션 축소 또는 대기
```

**Knowledge Base 근거:** "ADX-Based Regime" + "Strategy Selection by Regime"

---

### D-3. `volatility_filter` — 변동성 필터

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| atr_period | 7~21 | 14 | ATR 기간 |
| max_atr_ratio | 3~10% | 5.0 | ATR/가격 비율이 이 이상이면 거래 중단 |
| reduce_at | 2~7% | 3.0 | 이 비율 이상이면 포지션 반감 |

**동작:**
- ATR/가격 > 5% → 극단적 변동성 → 신규 진입 차단
- ATR/가격 > 3% → 높은 변동성 → 포지션 50% 축소

**Knowledge Base 근거:** "ATR Ratio" — BTC 5%+ = 극단, 리스크 축소 필수

### D-4. `session_filter` — 거래 세션 필터

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| allowed_sessions | - | ["us","eu"] | 허용 세션 |
| block_weekend | true/false | false | 주말 거래 차단 |

**세션 정의 (UTC):**
- 아시아: 00:00~08:00 (낮은 변동성, 횡보)

- 미국: 13:00~21:00 (최고 변동성, 주요 무빙)
- 겹침: 13:00~16:00 (최대 유동성)

**Knowledge Base 근거:** 주말 유동성 30~50% 감소, 스프레드 확대, 플래시 크래시 위험 증가

## F. 레버리지 & 마진 (별도 설정)

시그니처 모듈과 독립적으로 봇 레벨에서 관리.

| 파라미터 | 범위 | 설명 |
|----------|------|------|
| leverage | 1~20x | 레버리지 배수 |
| margin_mode | "isolated"/"cross" | 마진 모드 |

**안전 레버리지 공식:**
```
안전 레버리지 = 1 / (2 × ATR비율)
권장: 안전 레버리지의 50%만 사용
예시: ATR/가격 = 3% → 안전 = 16.7x → 권장 = 8x
```

## G. 봇 레벨 리스크 (시그니처 밖)

시그니처와 무관하게 봇이 항상 강제하는 안전장치.

| 파라미터 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| daily_max_loss_pct | 1~5% | 3% | 일일 최대 손실 → 초과 시 24h 매매 중단 |
| weekly_max_loss_pct | 3~10% | 7% | 주간 최대 손실 |
| max_drawdown_halt | 8~25% | 15% | 계좌 낙폭 → 봇 완전 정지 |
| daily_trade_limit | 5~100 | 50 | 일일 최대 거래 횟수 |
| consecutive_loss_pause | 2~5 | 3 | 연속 N회 손실 시 쿨다운 |
| cooldown_minutes | 5~60 | 30 | 쿨다운 시간 |

**낙폭별 대응 프로토콜:**
```
0~5%  → 정상 운영
5~10% → 포지션 50% 축소
10~15% → 최소 사이즈만, 전략 리뷰
15~20% → 신규 진입 중단, 기존 포지션만 관리
20%+  → 봇 정지, 전체 리뷰
```
